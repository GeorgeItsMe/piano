# Нота ↔ Клавиша

Тренажёр нотного стана: связывает то, что видишь в нотах, с тем, что нажимаешь на клавиатуре.

**Открыть:** двойной клик по `index.html` — это один самодостаточный файл, интернет не нужен.

## Курс

Лестница из 11 юнитов и 39 уроков — от одной ноты до обоих ключей с диезами и добавочными линейками. Следующий урок открывается, когда пройден предыдущий.

- В уроке три жизни. Промахнулся — нота возвращается в конец очереди, пока не возьмёшь её верно.
- Клавиатура на время урока сужается до нужного участка, чтобы не искать ноту среди 88 клавиш.
- За урок дают опыт, за урок без ошибок — три звезды. Считаются дни подряд и дневная цель.
- В поздние уроки подмешиваются ноты, на которых ты чаще ошибался. Отдельная кнопка «Разминка на трудных нотах» собирает урок целиком из них.

Порядок тем строился по одному правилу: **одно новое измерение за раз**. Сначала диапазон внутри скрипичного ключа, потом второй ключ, потом добавочные линейки, потом альтерация, и только в конце — далёкие октавы. Курс начинается с соль первой октавы (нота на линейке, вокруг которой завивается ключ), а не с до первой: до живёт на добавочной линейке, то есть это исключение, и давать его раньше правила нельзя. Задание «поставь ноту на стан» появляется только в четвёртом юните и никогда не дебютирует на добавочных линейках.

Программа лежит в [assets/course.json](assets/course.json) — её можно править, не трогая код. Проверка сверяет номера нот с названиями и ловит бессмысленные уроки:

```sh
node tools/check-course.mjs
```

## Свободный тренажёр

| Режим | Что делаешь |
|---|---|
| Свободно | Нажимаешь клавиши — нота появляется на стане, латунная нить связывает её с клавишей. Можно брать аккорды. |
| Нота → клавиша | На стане нота, ты ищешь её на клавиатуре. |
| Клавиша → нота | Клавиша подсвечена, ты ставишь ноту на стан — кликом по нужной линейке или промежутку. Под курсором идёт полупрозрачная подсказка-нота. |
| Название | На стане нота, выбираешь имя из семи кнопок. |

Промах не стирается, а показывается: заданная нота остаётся на стане чернилами, а рядом встаёт красная — та, куда ты попал, — и к нажатой клавише тянется красная пунктирная нить. Видно не «мимо», а насколько мимо: на ступень выше, на терцию, октавой не туда. В режиме «Название» красной встаёт нота, которую ты назвал, в ближайшей к заданию октаве.

Серия, рекорд и точность считаются по всем режимам; трудные ноты копятся в отдельной карточке. Всё хранится в `localStorage` браузера.

## Две картины стана

- **Единая лестница** (по умолчанию) — скрипичный и басовый ключи соединены в одну непрерывную линейку ровно так, как они соотносятся по высоте: до первой октавы стоит точно посередине, на общей добавочной линейке. Удобно, чтобы понять устройство.
- **Как в нотах** — два отдельных стана с обычным просветом.

## Играть можно с чего угодно

- Мышью или пальцем по экранной клавиатуре. Диапазон переключается прямо над клавишами: 2 октавы, 4 октавы или все 88. На все 88 клавиатура при необходимости прокручивается вбок, подписи ужимаются до одних «до», а подсвеченная клавиша сама подъезжает в видимую часть.
- С клавиатуры компьютера: нижний ряд `Z X C V B N M` — белые, `S D G H J` — чёрные, верхний ряд `Q…U` — октавой выше. Разбор идёт по физическим кодам клавиш, поэтому русская раскладка не мешает. `←` `→` сдвигают октаву.
- С MIDI-клавиатуры — кнопка «Подключить» в настройках.

Звук — синтез на Web Audio, без сэмплов.

## Как это собрано

```
src/style.css        оформление
src/markup.html      разметка
src/app.js           ядро: теория, отрисовка стана, клавиатура, свободные режимы
src/course.js        курс: лестница уроков, жизни, звёзды, опыт
assets/glyphs.txt    контуры нотных ключей и знаков альтерации
assets/course.json   программа курса
build.mjs            сборка → index.html и dist/artifact.html
tools/tighten.mjs    пересчёт границ глифов и опорных линий
tools/check-course.mjs проверка программы курса
```

Ядро и курс собираются в одну область видимости: курс подменяет выбор ноты через три точки подключения (`HOOK.pick`, `HOOK.beforeRound`, `HOOK.onAnswer`) и пользуется отрисовкой стана напрямую, без глобальных переменных.

```sh
node build.mjs
```

`index.html` лежит в репозитории готовым — чтобы можно было просто открыть файл, не собирая. `public/` и `dist/` собираются и в git не хранятся.

## Развёртывание на Vercel

Импортируй репозиторий на [vercel.com/new](https://vercel.com/new) — настройки подхватятся из `vercel.json`: сборка `node build.mjs`, раздача из `public/`. Зависимостей нет, установка пропускается. Каждый push в `main` пересобирает сайт из исходников.

Ключи не набраны шрифтом, а вшиты как SVG-пути: контуры вынуты из системного `Segoe UI Symbol`, так что на любой машине они выглядят одинаково и ничего не подгружается извне.

Опорные точки выверены по самим контурам, а не на глаз: у басового ключа линия фа проходит ровно между двумя точками (и расстояние между ними задаёт масштаб — это ровно один межлинейный промежуток), у бемоля опора — центр чаши. Скрипичный ключ посажен по канонической пропорции: спираль на 0.625 высоты глифа сверху, полная высота 7.02 промежутка.
